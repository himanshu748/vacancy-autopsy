# Vacancy Autopsy — working scope

For job seekers deciding whether to invest time in an advertised opening. Outcome: inspect a timestamped, reproducible first-party check before applying.

Implemented journey: submit an official Greenhouse, Lever or Ashby job URL (or supply one alongside an advertisement), inspect a qualified verdict with source evidence, download the report, and recheck it. Optional SerpApi discovery and restricted Browserbase capture preserve separate source artifacts; Auth0 can authorize a private digest-bound reviewer approval. Deterministic identity matching remains the baseline. These provider integrations are locally tested and live-provider unverified. Ten sponsor categories are targets, never assumed verified.

Acceptance: live public ATS requests; strict job-ID matching; incomplete/error responses remain inconclusive; hashed evidence with capture times; persistence/recheck; responsive keyboard-operable UI; labeled illustration; tested failure cases. No automatic applications or unsupported employer-intent claims.

Phases: (1) official-source verifier and useful UI; (2) real labeled corpus and model experiments; (3) sponsor services and recovery/approval evidence; (4) deployment and submission only under user authorization.

Constraints: no Arduino or DigitalOcean. Routine local implementation, verification and Entire setup are authorized. The user authorized one local source commit for an Entire anchor; it was created without a push. The user subsequently authorized a private `himanshu748/vacancy-autopsy` repository, a source commit and source-branch push. This excludes checkpoint/session refs and local evidence. Spending, paid/provider activation, publication, deployment and later unrelated source changes still require applicable authorization. No training run or paid model call has occurred. Keep textile restoration out of this project.

Hosting boundary: localhost by default. Optional hosted mode requires a public HTTPS origin, complete Auth0 configuration and MongoDB persistence. Every permitted human reviewer shares one private workspace. It is not a tenant-isolated product and has no public report publisher. A real tenant login, database receipt and hosted journey remain release gates.

Observed lead: the OppIDX Figma advertisement still presented an Apply link to job `6144755004`; the complete employer feed did not contain that ID and the application URL redirected to careers. This is a point-in-time mismatch, not evidence of intent or prior removal.

Naming: Vacancy Autopsy. Tagline: The internet remembers jobs that employers have already removed. This describes the problem hypothesis, not a finding from the initial illustrative example.

Evidence vocabulary: "Verified open" means the exact posting is in the checked public source at the recorded time, not that a hire will happen. "Not currently listed" means absent from a successfully validated complete public board response, not proved fake or fraudulent. "Inconclusive" covers ambiguous identity, access errors, rate limits, partial data, and unsupported sources. A prior timestamped positive observation is needed to claim that a posting was removed.
